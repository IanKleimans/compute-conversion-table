What this measures

  • Break-even utilization: rent per GPU-hour divided by what that hour earns at full load, at the median list price across providers. It is a best case: it assumes the list price is earned and ignores every cost except rent.
  • Exchange rate: output per GPU on a chip divided by output per GPU on an H100, same model, same software release, same speed per user.
  • Software gain: how much more the same H100 produces than in the first month, from software updates alone.

How it is built

  • Output per GPU: SemiAnalysis InferenceX benchmark runs with vLLM, 1,024 input and 1,024 output tokens per request. Each day's best result meeting the speed target becomes a monthly median.
  • Rent: on-demand monthly median from the GetDeploying GPU price dataset (CC BY 4.0).
  • List prices: OpenRouter's public price list, per provider, saved daily.
  • After a model's last benchmark month, its output is held flat for up to six months (dashed lines) while rent keeps updating.

Caveats

  • Benchmark setups are tuned by chip vendors and the community, and the requests are synthetic.
  • Some 2026 months rest on one to four benchmark runs.
  • GPU rental indices disagree with each other; this page uses one of them.
